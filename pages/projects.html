Arxeion

Released

A Windows launcher that turns the list of installed programs into something you can actually organise.

Arxeion finds installed applications by scanning the Windows registry and loads their icons asynchronously, so the interface never waits on them. You can sort apps into categories and hide the ones you never use.

Two views cover two jobs: a grid for launching, and a management view for categories and hidden apps. Everything you set up is saved as JSON, and a global shortcut written in AutoHotkey v2 brings the launcher up from anywhere.

The interface is immediate-mode (Dear ImGui) rendered through DirectX 11, and the whole program ships as a single standalone executable.

Photo border

Live

Prepares photos for Instagram without letting it crop them: a uniform border, the right format, and a carousel slicer for wide shots.

Photo border adds a uniform white border to your photos and exports them at 1080 × 1350, the 4:5 portrait format. Border width is set from the interface.

Wide photos can be sliced across 2 to 5 carousel slides, so a panorama becomes one continuous swipe. Results are exported together as a zip.

It is plain HTML, CSS and JavaScript on the Canvas API, with JSZip for packaging. Images are processed in your browser and never uploaded, and the page can be hosted statically with no login.

Valorant tracker

In development

A Tracker-Network-style stats page, built for a small circle of friends instead of the public.

The idea is simple: the usefulness of a stats tracker, without the ads. It is for private use among friends, so it can stay small and focused.

Data comes from the official Riot API: account lookup, match history and game content. A player’s current rank is derived from the competitive tier recorded in their latest competitive match.

LEGO tracker

In development

A web app to catalogue a personal LEGO collection, built as a learning project.

The tracker uses the Rebrickable API for catalogue data and Firebase (Auth and Firestore) for storage, and is planned for deployment on GitHub Pages. A valuation feature based on BrickLink market prices is being explored.

The longer-term goal is a physical counterpart: a modular wall of 20 to 50 ESP32-controlled drawers synced with the tracker. Each drawer is meant to weigh its contents to count parts, show the count on a 7-segment display, and light up when a search matches, including voice search.
